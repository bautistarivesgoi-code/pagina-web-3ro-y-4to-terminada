# Friv 2

Página de juegos con menú estilo PS4, hecha con HTML, CSS y JavaScript.

## Estructura

- `index.html`: la página
- `style.css`: estilos y animaciones
- `script.js`: menú, navegación, buscador y categorías
- `images/`: fondos, portadas (`covers/`) y gatitos (`nobg/`)

## Controles

- ◀ ▶ o rueda del mouse: cambiar de juego
- Enter o clic en el juego elegido: jugar
- `/`: ir al buscador
- En el celular: deslizar el dedo

## Cómo verla

Abrí `index.html` en el navegador.

## Publicar en GitHub Pages

1. Subí el contenido de esta carpeta a la raíz de tu repositorio.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Agregar un juego

En `script.js`, sumá un objeto a la lista `GAMES` con título, categoría, portada, gatito, enlace y descripción.
